Photope 隐私政策

生效日期：2026年11月16日
开发者：袁江

Photope 是一款使用 iPhone 系统照片图库的照片与视频整理工具。当前版本不要求注册账号，不接入广告、用户追踪或第三方统计 SDK，不会将你的照片、视频、位置或使用记录上传至开发者服务器。

照片访问与操作

经你授权后，Photope 使用 Apple PhotoKit 读取允许访问的照片、视频、相册及其相关信息，例如文件名、拍摄时间、尺寸、收藏状态，以及照片本身包含的拍摄位置。访问用于浏览、筛选、排序、显示详情和整理相册。你可仅授权部分照片，或在 iPhone 的“设置”中随时修改或撤销权限。

创建、重命名、移动、收藏、隐藏、复制或删除等操作会按你的指令修改系统照片图库，并遵循系统权限与确认流程。系统图库及 iCloud 照片的存储和同步由 Apple 及你的系统设置管理。隐藏照片的访问保护由系统照片设置控制。

本地存储与导出

语言、主题、相册置顶和显示偏好保存在设备本地。为分享、拷贝或复制照片，Photope 可能在应用临时目录准备文件；这些文件不主动上传至开发者服务器。选择分享目标或使用剪贴板时，接收应用会依据其自身隐私政策处理你主动提供的内容。

数据收集与第三方服务

当前版本不由开发者或嵌入的第三方 SDK 收集个人数据。你主动通过电子邮件联系支持时，开发者会收到你的邮箱、邮件内容及你主动附加的资料，仅用于回复和处理问题。请勿发送不必要的敏感照片或信息。本页面由 GitHub Pages 托管，访问页面时 GitHub 可能按其隐私政策处理网络请求信息。

你的选择

你可以在系统设置中管理照片权限，在系统照片中管理图片、相册与已隐藏项目。删除 Photope 会移除应用本地设置，不会自动删除系统图库中的照片。你通过 Photope 主动执行的图库修改可能同步至其他使用 iCloud 照片的设备。

儿童隐私

Photope 不要求提供年龄或身份信息，也不主动收集儿童个人信息。
